# ha-lafaer

[English](README.md) | 简体中文

在 Home Assistant 中管理 Lafaer LWR01 和 LWR02 人体存在传感器。通过侧边栏面板查看设备状态、控制指示灯，并调整检测参数。

## 功能

- 发现、接管、重命名和管理传感器。
- 查看有人/无人状态、照度、电量和设备信息。
- 查看 LWR02 的温度、湿度，以及 LWR01 的供电方式。
- 根据设备型号，调整检测模式、灵敏度、无人退出时间和暗光上报设置。
- 配置 LWR02 雷达距离分区和能量阈值，通过实时图表辅助调节。
- 雷达自学习、识别设备和参数重置。
- 查看调试信息，按需开启日志记录。
- 支持英语、简体中文和繁体中文，跟随 Home Assistant 的语言设置，其他语言默认使用英语。

本插件用于设备配置和状态查看，**不会为仪表盘或自动化创建持续更新的实体**。如设备支持，请继续通过 Matter 集成使用日常状态上报和自动化功能。目前不支持固件更新。

## 使用条件

- 支持自定义集成的 Home Assistant。声明的最低版本为 **2024.12.0**，建议使用仍受支持的新版本。
- 已加入 Thread 网络的 Lafaer **LWR01** 或 **LWR02**。
- 可用的 **Thread Border Router（Thread 边界路由器）**，以及 Home Assistant 到传感器的 IPv6 网络连通性。自动发现还需要 mDNS 可达。

本插件不负责将设备加入 Thread 网络。访问页面的手机或电脑不需要靠近传感器，关键是 Home Assistant 能够访问设备。

## 安装

### 通过 HACS 安装

1. 打开 HACS，在菜单中选择 **自定义存储库（Custom repositories）**。
2. 添加 `https://github.com/VAIO-Dong/ha-lafaer`，类型选择 **集成（Integration）**。
3. 找到 **Lafaer** 并下载。
4. 重启 Home Assistant。
5. 打开 **设置 → 设备与服务 → 添加集成**，搜索 **Lafaer** 并完成添加。
6. 从侧边栏打开 **Lafaer**。

如果 HACS 暂未提供下载，请使用下方的手动安装方式。

### 手动安装

1. 下载本仓库。
2. 将 `custom_components/lafaer` 复制到 Home Assistant 配置目录，确保存在 `/config/custom_components/lafaer/manifest.json`。
3. 重启 Home Assistant。
4. 在 **设置 → 设备与服务** 中添加 **Lafaer**，然后从侧边栏打开。

更新时，通过 HACS 下载新版本或替换集成文件，随后重启 Home Assistant 并刷新浏览器页面。

## 开始使用

### 添加传感器

设备列表分为已接管设备和发现的设备。点击 **接管** 添加传感器，或点击 **扫描** 重新搜索。右上角菜单提供手动接管入口。

> **App 与 Home Assistant 的管理功能互斥。**
> 传感器只能保存一套管理密钥。接管后会替换 App 的密钥，App 将无法继续管理该设备。再次通过 App 配对，会使 Home Assistant 的管理密钥失效。

设备是否可用取决于最近一次发现结果。如果显示可用但无法打开，请留意最后发现时间。

![已接管设备与发现的设备](assets/screenshots/device-list.png)

### 查看状态和控制设备

打开已接管的传感器，即可查看设备信息和当前读数。

| 型号 | 状态信息 |
| --- | --- |
| LWR01 | 有人/无人状态、照度、供电方式，以及可用时的电池电量 |
| LWR02 | 有人/无人状态、照度、温度、湿度和电池电量 |

首页提供指示灯开关、**识别设备** 和 **高级设置** 入口。点击设备名称旁的编辑图标，可以修改设备在本面板中的名称。

![设备信息、状态和控制入口](assets/screenshots/device-overview.png)

### 调整检测设置

进入 **高级设置**，调整设备控制和检测参数。LWR02 在仅 PIR 模式下显示红外设置，仅雷达模式下显示雷达设置，融合模式下两者均可设置。

展开 **雷达高级设置**，即可配置距离分区和能量阈值。点击对应距离段可开启或关闭该段的检测。图表中的柱形表示当前能量，横线表示设定阈值。

选择灵敏度预设后，对应阈值会自动填入；手动修改阈值后，灵敏度会切换为 **自定义**。调整完成后，点击对应分类的 **保存** 按钮应用设置。

## 注意事项

- **功耗与连接：** 面板仅在需要管理设备时连接。切换到其他浏览器标签页后会暂停更新，无人使用的连接会在一分钟后关闭。返回时重新连接可能需要几秒钟。
- **自学习：** 启动后，请在 30 秒倒计时内离开检测区域，等待完成提示后再调整设置。
- **能量图表：** 有人状态维持能量可能需要雷达工作一段时间后才会显示。
- **重置雷达参数** 会立即执行。移除设备和恢复出厂设置位于右上角菜单，需要二次确认。
- 从本面板移除设备，不会将其从 Matter Controller 中移除。
- 本项目是自定义集成。修改检测设置后，请先确认实际检测效果，再用于重要自动化。

## 常见问题与日志

**侧边栏没有出现 Lafaer：** 确认复制文件后已添加集成，重启 Home Assistant 并刷新浏览器。

**搜索不到设备：** 检查 Home Assistant 是否能够接收 mDNS 发现信息，尤其留意跨 VLAN 和容器网络配置。

**能发现设备但无法连接：** 检查 Home Assistant 到传感器的 IPv6 路由，以及 UDP **5683** 端口是否可达。其他 Matter Controller 能访问设备，不代表 Home Assistant 一定能访问。同时确认是否曾通过 App 重新接管设备。

**需要反馈问题：**

1. 在 **设置 → 设备与服务 → Lafaer** 的集成菜单中启用调试日志。
2. 复现问题，再关闭调试日志并下载日志文件。
3. 在 [GitHub Issues](https://github.com/VAIO-Dong/ha-lafaer/issues) 中提供 Home Assistant 和插件版本、设备型号和固件版本、复现步骤及相关日志。

系统日志位于 **设置 → 系统 → 日志 → Home Assistant Core**。面板设备列表右上角菜单也提供 **Debug（调试）** 入口，集成选项中可开启持久化日志记录。

公开反馈前请检查附件，不要上传密码、管理密钥、令牌或完整的 Home Assistant 配置。
